# Puking Cat: funny physics timing game

Puking Cat is a free mobile game by Ivanna Kaceviča at Happycode Studio in Latvia. Tap once to lock the angle, then tap again to lock the power. Launch slime at furniture, avoid hazards and chase three stars.

- [Official game website and press kit](https://happycode.studio/pukingcat/)
- [Download for iPhone and iPad](https://apps.apple.com/app/id6787404657)
- [Download for Android](https://play.google.com/store/apps/details?id=studio.happycode.puking_cat)
- [Watch gameplay](https://youtu.be/AISXPHAope4)
- [Project story on Devpost](https://devpost.com/software/puking-cat-the-game)

The game contains ads and in-app purchases. An optional Remove Ads subscription removes full-screen ads.
